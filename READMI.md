# MAILFLOW

## Описание проекта

MAILFLOW — веб-приложение для управления email-рассылками.

Сервис позволяет пользователям создавать рассылки, управлять получателями, отправлять сообщения вручную, отслеживать историю попыток отправки и получать статистику по своим рассылкам.

Проект разработан на основе Django с использованием PostgreSQL, Redis и Bootstrap.

---

# Основной функционал

## Пользовательская система

Реализована полноценная система пользователей:

- регистрация пользователя;
- подтверждение email адреса;
- авторизация и выход из системы;
- восстановление пароля через email;
- редактирование профиля пользователя;
- загрузка аватара;
- управление персональными данными.

---

# Управление рассылками

Пользователь может:

- создавать рассылки;
- редактировать свои рассылки;
- удалять свои рассылки;
- просматривать список своих рассылок;
- запускать рассылку вручную;
- останавливать активные рассылки.

Для рассылки задаются:

- название;
- дата и время начала;
- дата и время окончания;
- сообщение;
- список получателей.

---

# Отправка рассылок

Реализована ручная отправка сообщений.

Перед отправкой выполняется проверка:

- текущее время должно находиться между временем начала и окончания рассылки;
- рассылка должна иметь статус "Запущена".

При отправке каждому получателю:

- выполняется отправка через Django `send_mail()`;
- создаётся запись об успешной попытке;
- либо сохраняется ошибка отправки.

---

# История попыток отправки

Для каждой попытки сохраняются:

- дата и время отправки;
- статус отправки;
- ответ почтового сервера;
- связанная рассылка;
- получатель.

Это позволяет:

- анализировать эффективность рассылок;
- отслеживать ошибки доставки;
- формировать статистику.

---

# Получатели рассылок

Пользователь может:

- создавать получателей;
- изменять данные получателей;
- удалять получателей;
- использовать их в своих рассылках.

Хранятся данные:

- email;
- ФИО;
- комментарий.

---

# Роли пользователей

В проекте реализована ролевая модель.

## Обычный пользователь

Может:

- работать только со своими рассылками;
- управлять своими клиентами;
- просматривать собственную статистику.

## Менеджер

Может:

- просматривать все рассылки;
- просматривать всех клиентов;
- просматривать пользователей сервиса;
- блокировать пользователей;
- отключать рассылки.

Права реализованы через Django Groups и Permissions.

---

# Статистика

На главной странице отображается:

- количество созданных рассылок пользователя;
- количество активных рассылок;
- количество получателей;
- количество успешных и неуспешных отправок.

---

# Кэширование

Для ускорения работы используется Redis.

В кэш помещаются:

- количество рассылок пользователя;
- количество активных рассылок;
- количество получателей.

Используется механизм:

- получение данных из Redis;
- при отсутствии данных — запрос к базе данных;
- сохранение результата в Redis.
